# Accessibility Notes

Current baseline:

- High-contrast visual interface.
- Keyboard-focusable buttons, tabs, selects, and controls.
- Pause control for motion reduction.
- Reduced-motion mode in the educator console.
- Dyslexia-friendly font mode in the educator console.
- Read-aloud narration and pronunciation support for selected science terms.
- Textual source notes and model limitations.
- Inline Why? explanations for planet and Sun fact blocks.
- In-app quiz and data comparison available as text.
- Student Mode provides simpler explanations and a vocabulary helper.

Recommended before commercial release:

- Full WCAG 2.1 AA audit.
- Screen-reader label audit for all tabs and controls.
- Keyboard shortcuts for solar system navigation.
- Captions/transcripts for any recorded narration.
- Color-blindness review for planet labels and quiz states.
- FERPA/COPPA planning if cloud accounts, teacher rosters, or hosted analytics are added.
