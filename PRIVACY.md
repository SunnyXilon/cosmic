# Privacy Notes

This local build does not include accounts, analytics, remote databases, advertising pixels, or network student tracking.

Student profile names, class name, quiz attempts, weak topics, badges, assignments, and custom questions are stored only in this browser's localStorage on this computer. They do not leave the device unless a teacher exports, prints, or manually shares them.

If a future version adds class rosters, progress tracking, or LMS export, the product should add:

- FERPA and COPPA review.
- School data processing terms.
- Teacher/admin consent flows.
- Data deletion controls.
- Minimal data collection defaults.
