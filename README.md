# Cosmic Drift Classroom

Cosmic Drift Classroom is a local, browser-based solar system teaching tool for projector, lab, and tablet use. It combines a Three.js solar system model with teacher controls, lesson prompts, quizzes, comparison data, standards notes, and source citations.

## Included Product Features

- NASA/JPL texture-mapped 3D planets.
- Dedicated Sun detail view with NASA-based core, layer, solar wind, and fusion explanations.
- Tilted solar system model with slow orbital motion.
- Polar axis rotation using NASA fact-sheet values.
- Educator console with Lessons, Controls, Quiz, Compare, Sources, and Product tabs.
- Student Mode with Junior, Middle, and High content levels; the selected level changes planet/Sun pages, lesson text, simulations, quizzes, feedback, and helper explanations.
- Teacher Dashboard with class progress, common weak topics, assignments, custom questions, CSV export, browser print/PDF, and worksheet printing.
- Pause, labels, axis display, speed control, and display scale controls.
- Expanded planet encyclopedia sections for every planet: overview, surface/atmosphere, classroom explanation, exploration, NASA data, and model notes.
- Adaptive planet-specific and Sun-specific quiz bank with feedback, simpler follow-up prompts, and weak-topic tracking after each answer.
- Interactive simulations for day/night, seasons, greenhouse effect, orbit speed, classroom scale, Saturn rings, and moon systems.
- Read-aloud narration, pronunciation buttons, reduced-motion mode, dyslexia-friendly font mode, and inline Why? explanations for body facts.
- Expanded content for dwarf planets, asteroid belt, Kuiper Belt, comets, major moons, missions, and common misconceptions.
- Student motivation tools: badges, planet passport, completion summary, and end-of-path recap support.
- No login, analytics, or student data collection in this local build.

## Important Model Note

Planet sizes, orbital distances, and time are visually compressed so the model fits a classroom screen. The Sources tab explains what is real data and what is a teaching-scale representation.
